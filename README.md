7 слайдов по `pptx/CONTENT-PROMPT.md`. Палитра: тёмно-синий / красный / белый.

## Локально

```bash
cd presentation
npm install
npm run dev
```

Открой http://127.0.0.1:5180/ · `F` — полный экран.

## Сборка

```bash
npm run build
```

Артефакт: `presentation/dist/`.

## Выложить на GitHub Pages

`gh` уже установлен. Нужен только вход.

1. В терминале Cursor:

```powershell
gh auth login
```

GitHub.com → HTTPS → Login with a browser.

2. Напиши в чат: **выложи на GitHub Pages**
